# Токены

Три слоя. Компоненты читают только второй.

| слой | где объявлен | кто владеет |
|---|---|---|
| 1. Тема — 10 цветов monkeytype | `frontend/index.html`, тег `<style id="themeColors">`; значения ставит `state/themes.ts` | внешний контракт: 187 тем, 52 файла css тем, 15 файлов funbox |
| 2. Семантика и шкалы | `frontend/src/styles/tokens.css` | наш |
| 3. Компоненты | `monkeytype.css`, `modes.css`, `components.css` | наш |

Правило одно: **слой 2 выводится только из слоя 1, слой 3 читает только слой 2.**
Найденный в компоненте `var(--sub-color)` — ошибка слоя, проверяется командой
из [decisions.md](decisions.md).

## Слой 1 — тема

Десять имён monkeytype. Переименовывать нельзя ни одно: на них держатся
187 тем и 67 файлов css.

`--bg-color` · `--main-color` · `--caret-color` · `--sub-color` ·
`--sub-alt-color` · `--text-color` · `--error-color` · `--error-extra-color` ·
`--colorful-error-color` · `--colorful-error-extra-color`

Плюс три переменные, которые темы тоже задают и потому считаются частью
контракта:

| имя | значение по умолчанию | кто задаёт | замер |
|---|---|---|---|
| `--roundness` | `0.5rem` | 2 темы (`dark_note`, `terrazzo`) | 438 |
| `--nav-focus-opacity` | `0` | 8 тем | — |
| `--themable-button-text` / `-hover-text` / `-bg` / `-hover-bg` | не задано | 26 тем | новое, в отчёте нет |

## Слой 2 — цвет

Ни одного захардкоженного значения, кроме затемнения под модалкой.

### Поверхности

| токен | выведен из | где стоит |
|---|---|---|
| `--surface-page` | `--bg-color` | фон страницы |
| `--surface-raised` | `--sub-alt-color` | кнопка, карточка, клавиша, строка таблицы под курсором |
| `--surface-sunken` | `--sub-alt-color` | поле ввода |
| `--surface-accent` | `--main-color` | активная кнопка, заполнение полосы |
| `--surface-muted` | `--sub-color` | `<kbd>`, подсказка-облачко |
| `--surface-inverted` | `--text-color` | нажатая клавиша экранной клавиатуры |
| `--surface-danger` | `--error-color` | опасное действие |
| `--surface-scrim` | `rgb(0 0 0 / 60%)` | затемнение под модалкой |
| `--selection-bg` / `--selection-fg` | `--main-color` / `--sub-alt-color` | выделение текста мышью, замер 456 |

`--surface-raised` и `--surface-sunken` сейчас равны. Разведены намеренно:
у них разный смысл, и когда тема захочет их различать, править надо будет
одну строку, а не тридцать правил.

`--surface-scrim` — единственный цвет не из темы. Вывести его нельзя:
коробка модалки покрашена `--bg-color`, и затемнение того же цвета
слило бы её с фоном. У monkeytype затемнение тоже чёрное.

### Текст

| токен | выведен из | где стоит |
|---|---|---|
| `--fg-main` | `--text-color` | основной текст |
| `--fg-muted` | `--sub-color` | ненабранные буквы, крупные подписи |
| `--fg-muted-readable` | `color-mix(in srgb, --sub-color 45%, --text-color)` | мелкий служебный текст |
| `--fg-accent` | `--main-color` | цифры результата, активный пункт меню |
| `--fg-on-solid` | `--bg-color` | текст поверх любой сплошной заливки |
| `--fg-error` | `--error-color` | ошибки |
| `--fg-error-extra` | `--error-extra-color` | лишние буквы |
| `--fg-error-vivid` / `-extra` | `--colorful-error-*` | ошибки в ярком режиме |

`--fg-muted-readable` — не украшение, а починка: мелкий текст на `--sub-color`
не проходит контраст в **145 темах из 187**, с подмешиванием — в 59.
Одна строка чинит 86 тем, числа в [contrast.md](contrast.md).

`--fg-on-solid` один на все заливки. Заводить отдельный «текст на акценте»,
«текст на приглушённом» и «текст на обратном» незачем: у monkeytype это
всегда цвет фона страницы.

### Скругления

| токен | значение |
|---|---|
| `--roundness` | `0.5rem`, замер 438 |
| `--radius-sm` | `calc(var(--roundness) / 2)` |
| `--radius-md` | `var(--roundness)` |
| `--radius-pill` | `999px` |
| `--radius-circle` | `50%` |

`--radius-sm` и `--radius-md` объявлены **на `*`, а не на `:root`** — и это
не небрежность. Переменная подставляется там, где объявлена: с `:root`
скругление посчиталось бы один раз от корневого `--roundness` и дальше
наследовалось готовым числом. Тема `dark_note` задаёт `--roundness: 5em`
прямо на `.button` и ноль на модалке командной строки — до `--radius-md`
её правка бы не дотянулась, и тема сломалась бы молча. Проверено замером:
на `dark_note` кнопка даёт `border-radius: 80px`, остальные элементы — 8px.

### Движение

У monkeytype ровно две длительности (замер 447), остальное — числа каретки
из их `caret.ts` (замер 453).

| токен | значение | где |
|---|---|---|
| `--duration-base` | 0.25s | базовая |
| `--duration-fast` | 0.125s | половинная: цвет кнопок и меню |
| `--ease-standard / inout / linear` | ease / ease-in-out / linear | |
| `--transition` | `var(--duration-fast) var(--ease-standard)` | имя оставлено прежним |
| `--transition-base` | `var(--duration-base) var(--ease-standard)` | |
| `--caret-duration-slow / medium / fast` | 0.15s / 0.1s / 0.085s | три скорости каретки |
| `--caret-blink-duration` | 1s | мигание |
| `--scroll-duration` | 0.15s | прокрутка строк |
| `--tape-duration` | 0.1s | лента |
| `--progress-duration` | 0.15s | заполнение полос |
| `--spinner-duration` | 0.8s | оборот крутилки |

При `prefers-reduced-motion: reduce` все длительности становятся `0.001ms`
одним блоком в `tokens.css`. Крутилка — исключение: её не гасят, а замедляют
вдвое, потому что остановленная крутилка неотличима от зависшей страницы.

### Брейкпоинты

Семь ступеней monkeytype, замер 458.

| токен | значение | что меняется |
|---|---|---|
| `--bp-2xs` | 331px | логотип мельчает, панель режимов ужимается |
| `--bp-xs` | 426px | поля 16px, кнопки меню 32px, футер мельче |
| `--bp-sm` | 721px | прячутся клавиатура и подпись логотипа, таблицы ужимаются |
| `--bp-md` | 849px | настройки складываются в одну колонку |
| `--bp-lg` | 1105px | поля страницы 24px вместо 32px |
| `--bp-xl` | 1361px | объявлена, правил нет |
| `--bp-2xl` | 1617px | объявлена, правил нет |

В `@media` переменные подставлять нельзя, поэтому там стоят те же числа
минус один пиксель: ступень — это минимальная ширина, с которой действует
раскладка. Все правила собраны в `components.css`, разделе «Брейкпоинты»,
чтобы адаптив не был размазан по трём файлам.

Две верхние ступени у monkeytype расширяют колонку контента, а у нас её
ширина закреплена — правило было бы пустым. Числа объявлены всё равно:
они должны лежать в одном месте.
