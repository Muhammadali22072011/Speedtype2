# SEO Speedtype 2 — что стало

[audit.md](audit.md). Домен: `speedtype.izzatullaev.uz`.

## Оговорка, без которой цифры врут

Пока шла работа, **проект правился параллельно другой сессией**: добавлялись
страница «о проекте», переключение темы по системе, подсказки в подвале,
новая панель режимов. За это время главный бандл вырос с 85,5 КБ до 97,3 КБ,
а css — с 16,1 до 28,4 КБ.

Это значит, что сравнение «было / стало» на мобильном профиле смешивает
две вещи: мои правки скорости и чужой новый код. Часть выигрыша съедена
ростом приложения. Где можно разделить — разделяю явно.

Чистые, не зависящие от роста цифры — блокировка отрисовки, сжатие,
кеширование и сторонние домены. Они ниже.

Было ноль страниц с текстом. Стало шесть:

| `/norms` | какая скорость нормальная: таблица уровней от 20 до 120 wpm | — |
| `/faq` | что такое wpm, raw, точность и ровность; 8 вопросов | `FAQPage` |
| `/russian` | тест на русском: почему цифра ниже, что мешает в ЙЦУКЕН | — |
| `/uzbek` | то же на узбекском языке, `lang="uz"` | — |
| `/about` | о проекте и лицензия GPL-3.0 (сделано параллельной сессией) | — |

Тексты FAQ лежат в `backend/app/data/faq.json` и импортируются страницей
на сборке — не копируются. Google требует, чтобы размеченный текст
совпадал с видимым, а две копии разошлись бы молча.

**Про расширенные результаты — честно.** Разметка `FAQPage` и `HowTo`
валидна, но обещать по ней «звёздочки в выдаче Google» нельзя: в 2023 году
Google убрал расширенные результаты `HowTo` совсем, а `FAQ` оставил только
государственным и медицинским сайтам. Разметка сделана как задел под другие
поисковики и на случай возврата — не как источник кликов.

## Что осталось несделанным

| пункт | почему |
|---|---|
| Кириллические адреса на живом сайте дают **502** вместо 404 | Ломается в цепочке деплоя, не в приложении. Подробности ниже |
| `label-content-name-mismatch` на `#themeIndicator` и `#versionIndicator` | Эти кнопки появились в подвале за несколько минут до сдачи, в параллельной сессии. Чинится одной строкой: убрать с них `aria-label`, тогда доступным именем станет видимый текст |
| Страницы под режимы «на минуту», «на 60 секунд» | Сделаны две языковые, у которых есть что сказать по-разному. Остальные отличались бы одним числом — это дублирующийся контент |
| Многоязычный интерфейс и `hreflang` | Решено сознательно: сайт русскоязычный. ~40 мест с русскими строками в коде — это отдельный проект |
| Google Search Console, Яндекс.Вебмастер | Требуют доступа к панели домена. Карта сайта готова к отправке |
| Динамическая картинка превью для результата | Отдельная работа: рендер png на лету, кеш, свой маршрут |

### Про 502 — что выяснено точно

Воспроизводится только на живом сайте, только для адресов с процентным
кодированием непечатных байтов:

```
/no-such-page  → 404   (правильно)
/%61%62%63     → 404   (правильно, это «abc»)
/abc%20def     → 502   (пробел)
/%D0%BD...     → 502   (кириллица)
/%2520         → 404   (двойное кодирование)
```

Последняя строка всё объясняет: `%2520` после одного декодирования
становится `%20` и остаётся корректным адресом, а `%20` после того же
декодирования становится настоящим пробелом и ломает строку запроса.
То есть **ровно один слой в цепочке декодирует путь** перед отправкой
в uvicorn.

Локально все четыре адреса отдают 404. Сырые байты в строке запроса
uvicorn отвергает с кодом 400 — и это правильно по RFC 9112. Проверено
на обоих его парсерах, `httptools` и `h11`: поведение одинаковое.
**Починить это в приложении нельзя**, запрос до него не доходит.
Лечится в конфигурации `cloudflared`.

Влияние небольшое: на сайте нет ни одного кириллического адреса, и все
новые сделаны латиницей намеренно. Краулер попадёт туда только по чужой
битой ссылке.

## Проверки, которыми это подтверждено

```bash
cd backend && .venv/Scripts/python -m pytest -q
```

87 тестов, из них 40 новых — на коды ответов, подстановку мета-тегов,
robots, карту сайта, экранирование пути и на то, что `/api` не перехвачен
catch-all.

```bash
cd frontend && npm run typecheck && npm test && npx vite build
```

Типы сходятся, 66 тестов проходят, сборка даёт 13 чанков вместо одного.

Отдельно проверено то, что ломается молча:

- собранный `dist`, поданный **через бэкенд**, а не через `vite dev`;
- сырой html каждого маршрута через `curl` — заголовки, описания,
  canonical и og смотрели без выполнения js;
- 404 на несуществующем адресе;
- защита от выхода за пределы `dist` тремя видами `../`;
- горизонтальное переполнение на ширине 390 px при настоящей мобильной
  эмуляции: `scrollWidth` равен вьюпорту на всех страницах;
- живой сайт `speedtype.izzatullaev.uz` — мета-теги на нём стоят.

   Без этого индексация начнётся сама, но позже.

   страниц в индексе. Ожидание — 9, по числу адресов в карте.

   но у скребка свой кеш — если карточка старая, помогает отладчик
   Facebook, он же сбрасывает кеш и для остальных.
4. **Починить 502** в конфигурации туннеля, если понадобятся адреса
   не на латинице.
5. **Дописать тексты**: «как увеличить скорость печати» — единственная
   страница из плана, которую не сделал.

Позиций не обещаю. Сайт стал индексируемым, быстрым и с шестью страницами
текста вместо нуля — остальное решает поиск.
